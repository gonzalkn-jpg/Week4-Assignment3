# Quick Quiz

A lightweight, browser-based trivia game built with plain HTML, CSS, and JavaScript. Test your general knowledge, build a streak by answering correctly, and try to complete every question without a mistake.

## About the project

Quick Quiz presents one multiple-choice question at a time with four answer buttons. Questions and answer choices are randomized for each run, and questions do not repeat during the same run.

- Correct answers increase your visible streak and move you to the next question.
- A wrong answer ends the run and displays your final streak.
- Answering every question correctly displays a congratulatory victory card.
- **Play Again** starts a fresh run and resets the streak.

The project has no external dependencies, build step, or server requirement.

## Installation

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

For example, double-click `index.html`, or right-click it and choose your browser. No additional installation is required.

## How to play

1. Read the question and choose one of the four answers.
2. Keep answering correctly to grow your streak. Each question appears only once per run.
3. If you answer incorrectly, review your final streak and select **Play Again** to start over.
4. Answer all questions correctly to see the victory card, then select **Play Again** to play another round.
