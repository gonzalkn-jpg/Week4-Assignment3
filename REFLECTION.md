## **What did I ask Copilot to help me build and how did I break down the problem?**
### I asked Copilot to help me build a simple, user-friendly html website containing a quiz game.
### I started by asking it to help me build the main idea of it: a simply html website which generates a random question
### and four clickable answer buttons, one of which is the right answer. If the user clicks the right answer button, it 
### would produce the next random question and add +1 to a visible streak counter. If the user clicks a wrong answer button,
### it would end the game, display the final streak and a "Try again" button, and reset the streak when the user tries again.
###
## **How did my approach to asking questions change as I worked?**
### As I worked, I began to make more specific suggestions focused on smaller details rather than making broader statements
### in my requests.
###
## **What parts of the development process with GitHub Copilot surprised me?**
### I was surprised by how quickly and efficiently Copilot was able to not only work based off of what I gave it, but also
### to carefully analyze my current files and make any necessary modifications for the program to work, such as converting
### a plain text file to an html file without me having to ask it to do it for me.
###
## **What did I learn about the technology I used that I didn't know before?**
### I became more aware of what a useful tool it can be when used ethically and correctly. I didn't know how advanced and
### intelligent this technology could be before I started working with it.
###
## **What would I do differently if I had to build this again?**
### I probably would have interacted with it more, narrowing my focus down to even more specific aspects and details. 
### I also would've liked to add a few more customizable aspects to the website, and to have asked Copilot more questions
### about how certain components work, so that I could understand it as thoroughly as possible.
